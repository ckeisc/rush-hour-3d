# Rush Hour 3D

A three.js 3D version of the Rush Hour sliding-block puzzle, built with Muse.

- 45° top-down 3D board, drag-and-drop cars, hotseat 1–4 players
- Undo, hints, sound; 20 levels from 4 kid warm-ups through authentic Jam cards to Jam 40 / The Great Escape (par 51)
- 10 pop-culture cars (DeLorean default hero) + Garage presets
- Phone-first UI: board fills the screen, icon-only top-level buttons, overflow menu

Play it live: https://ckeisc.github.io/rush-hour-3d/

Static site — just open `index.html` (or serve the folder); no build step. 2D Canvas fallback if WebGL is unavailable.
